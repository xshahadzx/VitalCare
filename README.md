# VitalCare

**VitalCare** is a full-stack online booking system that allows patients to search for and book appointments with doctors based on their preferences.

## Features

- Secure authentication system (login, logout)
- Doctor profiles with availability
- Booking system for appointments
- Search by doctor name or specialty
- Admin panel for managing doctors, users, and bookings
- Responsive and user-friendly UI

## Tech Stack

- **Frontend:** HTML, CSS, Tailwind CSS, JavaScript
- **Backend:** PHP 
- **Database:** MySQL
